# Provider marks

These locally bundled assets identify the provider beside a visible text label.
No image requests go to third-party servers when the app loads.

- `openai.svg`, `claude.svg`, `gemini.svg`, `grok.svg`, `openrouter.svg`: unmodified
  from [Lobe Icons](https://github.com/lobehub/lobe-icons),
  `@lobehub/icons-static-svg@1.91.0`, downloaded from
  `https://unpkg.com/@lobehub/icons-static-svg@1.91.0/icons/NAME.svg`.
  See the bundled MIT [LICENSE](LICENSE).
- `sakana.png`: unmodified [Sakana AI website logo](https://sakana.ai/sakana-logo-hero.png).
  CSS frames the fish symbol for compact display.

Brand marks belong to their respective owners; their use identifies integrations.
